# Juego del Ahorcado — Java

Implementación del clásico juego del ahorcado en Java, desarrollado como ejercicio de lógica de programación y manejo de estructuras de datos básicas.

## Descripción

El jugador debe adivinar una palabra oculta letra por letra antes de agotar sus intentos. El programa gestiona el estado del juego, valida las letras ingresadas y muestra el progreso en consola.

## Funcionalidades

- Selección aleatoria de palabras desde un banco de palabras
- Validación de letras ingresadas por el usuario
- Control de intentos restantes
- Visualización del progreso de la palabra

## Conceptos aplicados

- Lógica de control (condicionales, bucles)
- Manejo de Strings en Java
- Estructuras de datos básicas
- Entrada/salida por consola

## Tecnologías

- Java

## Cómo ejecutar

```bash
git clone https://github.com/Sebasve0810/taller-juego-ahorcado.git
cd taller-juego-ahorcado
javac "juego ahorcado"
java "juego ahorcado"
```
